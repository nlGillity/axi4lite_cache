\label{subsec:evicting_block}

Для каждого набора регистр MRU хранит индекс наиболее недавно использованной секции.
При попадании в MRU записывается индекс секции с запрашиваемым тегом.
При промахе блок считывает MRU выбранного набора и запускает \PRG. Генератор формирует индекс секции для замещения, исключая индекс из MRU. 
Стратегия NMRU (\textit{Not Most Recently Used}) исключает вытиснение наиболее недавно использованную секцию.
Допустимый индекс выдаётся логике управления кэшем для замещения строки и записывается в MRU.
