\subsection{Data Memory}
\label{subsec:data_memory}

Память данных состоит из банков: каждый хранит данные одной секции для всех наборов кэша.

Банк --- псевдодвухпортовая память с одним портом для чтения или записи. Запросы чтения поступают от логики кэша со стороны процессора, записи --- из канала R интерфейса AXI4-Lite внешней памяти. Тип доступа определяется текущей операцией кэша.

Индекс набора адресует все банки. На следующем такте память выдаёт данные всех секций выбранного набора.

Задержка операций чтения и записи составляет один такт.
