\subsection{Pseudo-Random Generator (PRG)}
\label{subsec:prg}

Для кэша с числом секций \verb|WAY_NUM| минимальная разрядность LFSR составляет

\begin{equation}
	N = \log_2( \verb| WAY_NUM |)
\end{equation}

триггеров. Полином обратной связи настраивается мультиплексорами между соседними разрядами LFSR. Для $i$-го коэффициента мультиплексор выбирает операцию XOR или прямое соединение.

Логика И-НЕ инвертирует биты сформированного индекса, совпадающие с битами индекса исключённой секции. При полном совпадении индексов инверсия формирует другой индекс.

В обычном LFSR нулевое состояние блокирующее: нулевая обратная связь не позволяет выйти из него. Здесь обратная связь зависит и от индекса исключённой секции. Логика И-НЕ может инвертировать отдельные совпадающие биты даже при неполном совпадении индексов. Это позволяет внести ненулевые биты в следующее состояние и выйти из нулевого состояния без отдельной логики восстановления.

\begin{warningbox}{Распределение секций для замещения строк}
	Для NMRU индексы секций должны генерироваться примерно с одинаковой вероятностью.
	
	Логика И-НЕ меняет функцию переходов LFSR, поэтому равномерность распределения не гарантируется.
	
	Перед настройкой \verb|SET_NUM| и \verb|WAY_NUM| проверьте выбранную конфигурацию LFSR на достаточно длинной последовательности: все допустимые индексы секций должны встречаться примерно с одинаковой частотой.
	
	При существенной неравномерности выберите другой полином обратной связи или увеличьте длину LFSR.
\end{warningbox}
