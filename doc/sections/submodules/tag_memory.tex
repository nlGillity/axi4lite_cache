\subsection{Tag Memory}
\label{subsec:tag_memory}

Память тегов состоит из банков: каждый хранит теги и биты достоверности одной секции для всех наборов кэша.

\begin{figure}[H]
	\includegraphics[width=16cm]{Tag_Memory.png}
	\caption{Схема памяти тегов (четырёхсекционный кэш)}
\end{figure}

Банк --- псевдодвухпортовая память с одним портом для чтения или записи. Чтение запрашивает логика кэша со стороны процессора, запись --- логика управления кэшем. Тип доступа определяется текущей операцией кэша.

Для хранения битов валидности используются D-триггеры (на рисунке не указаны). Счётчик хранит один кредит. Чтение и запись расходуют его, блокируя новое обращение до завершения текущего. Кредит восстанавливается при попадании или получении достоверного ответа внешней памяти по каналу \verb|R| или \verb|B| интерфейса AXI4-Lite. Его можно использовать в том же такте.

Задержка операций чтения и записи составляет один такт.
