\subsection{Приём запросов}

Транзакции процессора поступают в \Arbiter. Но \verb|AW| и \verb|W| транзакции перед перед этим проходят через \hyperref[subsec:buffer]{буферы} (см. \circled{A}{fig:cache}).
Кэш начинает запись только после приёма в буфферы адреса по \verb|AW| и данных по \verb|W|.
Если поступает только запрос чтения по \verb|AR| или полный запрос записи по \verb|AW| и \verb|W|, то транзакция проходит к \Arbiter по комбинационному тракту (никакой задержки на буфферах).

\subsection{Операция чтения}

Процессор передаёт адрес чтения по каналу \verb|AR| интерфейса AXI4-Lite. Адрес одновременно запускает чтение из \TagMemory и \DataMemory (см. \circled{B}{fig:cache}).

Индекс набора из адреса выбирает набор в обеих памятях. На следующем такте \TagMemory выдаёт теги и биты достоверности всех его секций, а \DataMemory --- их данные.

Блок \Comparator получает теги и биты достоверности из \TagMemory и запрашиваемый тег из адреса. Он параллельно сравнивает теги всех секций и определяет наличие строки в кэше (см. \circled{C}{fig:cache}).

\subsubsection{Попадание при чтении}

При попадании \Comparator устанавливает сигнал попадания и выдаёт индекс секции с запрашиваемым тегом через \verb|hit_way|.

По \verb|hit_way| блок \EvictingBlock обновляет наиболее недавно использованную секцию набора. Одновременно \verb|hit_way| выбирает данные секции из \DataMemory для передачи процессору по каналу \verb|R| (см. \circled{C}{fig:cache}).

Параллельное чтение \TagMemory и \DataMemory позволяет определить секцию и выбрать данные за один такт.

\subsubsection{Промах при чтении}

При промахе \EvictingBlock с помощью \PRG выбирает секцию для замещения строки, исключая наиболее недавно использованную (см. \circled{D}{fig:cache}). Индекс секции определяет место перезаписи тега в \TagMemory.

Одновременно адрес строки передаётся во внешнюю память по каналу \verb|AR|. Данные ответа по \verb|R| записываются в строку выбранного набора и секции в \DataMemory и одновременно передаются процессору по его каналу \verb|R| (см. \circled{C}{fig:cache}).

\subsection{Операция записи}
При сквозной записи данные записываются в кэш и во внешнюю память через AXI4-Lite.

Процессор передаёт адрес и данные по каналам \verb|AW| и \verb|W|. Адрес также поступает в \TagMemory (см. \circled{B}{fig:cache}). По индексу из адреса выбирается набор, а \Comparator сравнивает его теги с запрашиваемым, как при чтении (см. \circled{C}{fig:cache}).

\subsubsection{Попадание при записи}

При совпадении тега \verb|hit_way| указывает секцию для записи данных в \DataMemory (см. \circled{C}{fig:cache}). Адрес и данные также передаются во внешнюю память по каналам \verb|AW| и \verb|W|.

\subsubsection{Промах при записи}

При отсутствии совпадения \EvictingBlock с помощью \PRG выбирает секцию для замещения строки, исключая наиболее недавно использованную (см. \circled{D}{fig:cache}).

В строку выбранного набора и секции записываются тег в \TagMemory и данные в \DataMemory (см. \circled{C}{fig:cache}). Одновременно адрес и данные передаются во внешнюю память по каналам \verb|AW| и \verb|W|.

\subsection{Подсчёт попаданий и промахов}
Блок \StatisticsBlock считает попадания и промахи по сигналам \Comparator для анализа производительности при моделировании.

\begin{infobox}{Только для моделирования}
	Блок \StatisticsBlock не синтезируется и не требует аппаратных ресурсов.
\end{infobox}
